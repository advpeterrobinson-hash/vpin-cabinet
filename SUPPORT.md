# Support

Virtual Pinball Cabinet is a community engineering project. Support is best-effort and happens through the official GitHub repository.

Official project:

https://github.com/advpeterrobinson-hash/vpin-cabinet

## Where to ask

Use a GitHub issue when you have a reproducible project problem, design question, measurement contribution, or fabrication result.

Choose the closest issue template:

- **Bug report** — scripts, validation, generated CAD, documentation, or reproducible project defects.
- **Design proposal** — mechanical, electrical, CNC, service, or architecture changes.
- **Hardware measurement** — measured dimensions for hardware that blocks CNC release.
- **Manufacturing feedback** — CNC, material, assembly, tolerance, fit, or proof-test experience.

For a small documentation correction, a focused pull request is also welcome.

## Before opening an issue

Please include:

- the commit or release you used;
- affected part IDs or subsystem when known;
- actual measurements and datums when geometry is involved;
- screenshots/photos where useful;
- exact validation or error output for software/build failures;
- whether you changed the design before the problem occurred.

Do not report an old dimension from a historical branch as a current defect without first checking the active project status.

## Security and safety

For information-security vulnerabilities, follow [SECURITY.md](SECURITY.md).

For mechanical, electrical, thermal, fire, structural, or service hazards, follow the physical-safety reporting instructions in [SECURITY.md](SECURITY.md).

## Manufacturing status

A public source file is not automatically approved for CNC production.

Check the project status, hardware-freeze matrix, measurement gates, and proof-test requirements before fabrication.

Commercial users remain responsible for satisfying the licence, applicable laws, electrical requirements, product-safety obligations, and any certification requirements that apply to products they make or sell.
