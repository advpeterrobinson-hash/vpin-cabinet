# Cable-route label scheme v0.11

Every harness and raceway should carry a short route code in the drawings, BOM and assembly manual.

- `A-AC` — AC mains
- `B-12` — 12 V high-current/DOF power
- `B-24` — 24 V high-current/DOF power
- `C-DATA` — USB/Ethernet/controller data
- `C-LED` — LED data / logic
- `D-AUDIO` — low-level audio
- `E-PF` — playfield display service loop
- `E-BB` — backbox display/service loop
- `BB-P1` — primary backbox cable passport
- `BB-P2` — reserve backbox cable passport

The final CNC/assembly drawings should mark route anchors and passage IDs so a first-time builder can reproduce the intended harness path without improvisation.
