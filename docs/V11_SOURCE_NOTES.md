# v0.11 source notes

External references used to inform this stage include:

- Pinscape Build Guide backbox/cabinet ventilation and WPC cabinet practices;
- Way of the Wrench virtual-pinball build series as a practical build reference;
- virtual-pinball-cabinet.com backbox/cable-management examples;
- community DOF build inventories showing common feedback devices and power-domain needs.

These references are used to identify classes of hardware and practical packaging concerns. Final electrical design values will be based on the selected parts' vendor documentation and measured current draw.
