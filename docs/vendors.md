# Parts and Services Vendors

## CNC Fabrication

### Cutter CNC

Website: https://www.cuttercnc.com/

Location:
São Paulo - SP, Brazil

Status:
Prospective CNC fabrication provider.
Consult before finalizing manufacturing files.

Services relevant to this project:
- CNC router cutting
- Pocket/recess machining
- Drilling
- Engraving
- 2D machining
- 3D machining where required

Supported project materials include:
- Plywood / compensado
- Marine plywood / compensado naval
- MDF
- MDP
- Solid wood
- Acrylic
- Polycarbonate
- PVC and various engineering plastics

Published machine capacity:
- Maximum length: 3000 mm
- Maximum width: 2000 mm
- Maximum machining height: 200 mm

Project-file requirements:
- Files should be supplied at 1:1 actual size
- Material must be specified
- Material thickness must be specified

Published supported formats include:

2D:
- DXF/DWG
- PDF
- EPS
- AI/CDR

3D:
- STL
- 3DM
- DXF
- OBJ
- other supported CAD formats

Important:
- Provider performs cutting/machining only.
- Painting, coating, polishing and final finishing are not included.
- Final tool diameter, tolerances, kerf/offset strategy,
  dogbone requirements and plywood measured thickness must be
  confirmed with the provider before generating production files.

Project intent:
Use Cutter CNC for an early design-for-manufacture consultation
before the cabinet CAD is frozen, and later obtain a quotation for
the CNC-cut cabinet kit.

Questions for consultation:
1. Preferred production file format: DXF or DWG?
2. Preferred layer convention for:
   - through cuts
   - pockets
   - drilling
   - engraving
3. Available router bit diameters.
4. Minimum practical internal radius.
5. Whether dogbones should be drawn by us or generated by CAM.
6. Typical dimensional tolerance in 18 mm plywood.
7. Whether they source plywood or require customer-supplied sheets.
8. Recommended plywood grade for painted cabinetry.
9. Whether both-face machining is available.
10. Method used for registration when machining both faces.
11. Minimum spacing required between nested parts.
12. Whether tabs/bridges should be included in our drawing or their CAM.
13. Cost difference between simple 2D cutting and pocket/dado machining.
14. Whether they can drill pilot holes and threaded-insert locations.
15. Maximum acceptable file size and preferred FreeCAD export workflow.
